# Auto-populate Verzeichnis field based on composer

When a known composer is entered, automatically populate the catalog/Verzeichnis field with the appropriate system:
- Mozart → K. (Köchel-Verzeichnis)
- Bach → BWV (Bach-Werke-Verzeichnis)
- Beethoven → Op. / WoO
- Schubert → D. (Deutsch-Verzeichnis)
- Haydn → Hob. (Hoboken)
- Vivaldi → RV (Ryom-Verzeichnis)

User can still override or clear the auto-populated value.
