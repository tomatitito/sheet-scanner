# Add musical key field to sheet music data model and UI

Add a field for the musical key of the piece (e.g., A major, B minor, C major, F# minor).

Considerations:
- Support both major and minor keys
- Consider using proper notation (e.g., F♯ vs F#, B♭ vs Bb)
- Field should be optional (some pieces are atonal or have no fixed key)
- Could offer dropdown/autocomplete for standard keys
